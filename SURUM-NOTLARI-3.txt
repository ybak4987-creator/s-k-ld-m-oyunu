SIKILDIM! — OYUN MERKEZİ 3

Bu sürümde:
- Kolay modların soru ve oyun zorluğu düşürüldü.
- Mantık testinde 40 kolay ve 10 orta soru bulunur.
- Genel kültür havuzunda 130 bilgi, kolay seçim havuzunda 59 bilgi vardır.
- Doğru/Yanlış oyunu başlangıçta kolay bilgi havuzunu kullanır.
- Sayı dizisi havuzunda 50 örnek vardır; çoğunluğu temel sayma ve küçük artış/azalış örnekleridir.
- 111 kelimelik havuz ve kolay kelime seçimi bulunur.
- Aynı soru veya içerik, havuz tamamı kullanılmadan tekrar seçilmemeye çalışılır.
- Mümkün olduğunda art arda aynı kategori veya oyun türü seçilmez.
- Renk ve Dikkat oyununda seçenek sayısı sadeleştirilmiştir.
- Desen Hafızası kolay modunda bir hata hakkı vardır ve desen tekrarları azaltılır.
- Kod Kırıcı ve Kelime Zinciri için daha anlaşılır oyun yönergeleri eklenmiştir.
- Oyun kartları, başlıklar ve oyun içi düzenler sadeleştirilmiştir.
- Marka klasör adı Türkçe noktasız ı harfiyle “sıkıldım” olarak yazılmıştır.

KURULUM:
1. ZIP'i çıkart.
2. “sıkıldım” klasörünü terminalde aç.
3. npm install
4. npm run dev

Kontrol notu:
Kaynak kodlarının sözdizimi, yerel import hedefleri, veri havuzları ve soru tekrar mantığı kontrol edilmiştir. Bu teslim hazırlanırken bağımlılık yüklemesi zaman aşımına uğradığından tam npm run build doğrulaması tamamlanamamıştır. Kurulumdan sonra npm run typecheck ve npm run build çalıştırılması önerilir.
