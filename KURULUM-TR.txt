SIKILDIM! — OYUN MERKEZİ 3.1

KURULUM (Windows / macOS / Linux)

1. ZIP dosyasını bir klasöre çıkart.
2. Açılan sıkıldım klasörünü VS Code veya terminal ile aç.
3. Terminalde şu komutu çalıştır:

   npm install

4. Geliştirme sunucusunu başlat:

   npm run dev

5. Terminalde verilen yerel adresi tarayıcıda aç (genellikle http://localhost:5173).

DERLEME VE KONTROL

   npm run typecheck
   npm run build

OYUNLAR VE İÇERİKLER

- Oyunlar ve soru havuzları src/data klasöründedir.
- Kolay moddaki sorular günlük hayattan ve temel bilgilerden seçilmiştir.
- Mantık testinde kolay ve orta sorular ayrı tutulur; Karışık mod ikisini de kullanır.
- Doğru/Yanlış oyunu başlangıçta kolay bilgi havuzunu kullanır.
- Son kullanılan soru, kelime ve oyun kategorileri mümkün oldukça art arda gelmeyecek şekilde seçilir.
- Tekrar geçmişi ve kişisel rekorlar tarayıcının localStorage alanında saklanır.
- Tarayıcı verileri temizlenirse tekrar geçmişi ve yerel rekorlar silinebilir.
- Arayüz ve marka yazımı SIKILDIM! şeklindedir. Proje klasörü Türkçe dotless ı harfiyle sıkıldım olarak adlandırılmıştır.
